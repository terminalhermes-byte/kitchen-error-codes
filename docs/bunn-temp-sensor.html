Bunn C-Series Coffee Maker Error: Temp Sensor

Temperature Sensor Bad

Potential Cause:
Tank temperature sensor reading is invalid.

How to Fix It:

1. Descale the tank (scale buildup on sensor).
2. Check sensor wire continuity.
3. Replace temp sensor.
