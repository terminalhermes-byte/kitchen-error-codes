True GDM Series Error: H1

High Temp Alarm

Potential Cause:
Cabinet temp is above safe limit (>40°F for 1 hour).

How to Fix It:

1. Check if door was left open.
2. Clean the condenser coil.
3. Check evaporator fan operation.
